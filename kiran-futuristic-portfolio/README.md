# KIRAN.DEV — Futuristic Portfolio

A futuristic cyber/AI themed portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the folder.
2. Open `index.html` in a browser.

For best results, use VS Code + Live Server.

## Before deploying
Replace the placeholder links in `index.html`:
- GitHub
- LinkedIn
- Email

You can also add:
- your profile photo
- your GitHub project URLs
- resume PDF
- certifications
- real internship/experience details

## Deploy to Vercel
Create a GitHub repository, push these three files, then import the repository into Vercel as a static site.

No backend is required.
